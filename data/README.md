# data/

Datasets used by the audit engine and demo.

- `synthetic/` — generated by the audit engine (decisions.md D5). **Every file here is synthetic**, and filenames carry a `synthetic_` prefix so this is obvious wherever they end up. They are reproducible from a fixed seed, so regenerate them rather than hand-editing.
- `public/` — any real public Indian municipal tonnage series tried for the Benford check. Record the source and the result in `docs/data-sources.md` before using it anywhere judge-facing.

Nothing in this folder is live MCD data.
